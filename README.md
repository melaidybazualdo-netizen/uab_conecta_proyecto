# UAB Conecta - Sistema de Gestión de Trámites

Aplicación web fullstack desarrollada para la gestión de trámites universitarios, con autenticación JWT, persistencia en MongoDB y empaquetamiento en contenedores Docker.

## 🛠️ Stack Tecnológico
- **Frontend:** React.js + Tailwind CSS (Vite)
- **Backend:** Node.js + Express.js (REST API)[cite: 1]
- **Base de Datos:** MongoDB con Mongoose ODM[cite: 1]
- **Seguridad & Documentación:** JWT, Bcryptjs, Swagger OpenAPI 3.0[cite: 1]
- **Contenedores:** Docker & Docker Compose[cite: 1]
